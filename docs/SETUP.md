# Quizit! setup

Follow the complete [README](../README.md#windows-one-time-setup). On Windows, load the extension directory, copy your own ID from Preferences, and double-click SETUP.cmd. The helper checks/downloads Ollama and the local model and configures sign-in startup. Use -NoAutoStart for process-scoped setup without persistent account changes. Browser permission steps remain manual.

Never share an extension ID copied from another computer: use the ID shown by your installation. No API key or Codex runtime is required.
