Start with Quizit!.

  1. Load this extension folder unpacked through Edge/Chrome Extensions > Developer mode > Load unpacked.
  2. Open Preferences in the sidebar and copy your own Extension ID.
  3. In the extracted project root, double-click SETUP.cmd and paste your Extension ID. It checks/installs Ollama and downloads the local model if needed.
  4. Setup starts a loopback-only server and configures automatic sign-in startup. The model still unloads after every task. If an existing server blocks the origin, quit that instance yourself and rerun.
  5. Add a page/file, choose output, level and counts, and click Start creating. Choose Mind map / flowchart for a visual overview and open the Map tab. English OCR runs locally when needed. For direct local PDF access, enable Allow access to file URLs once, or use Add file.

Read README.md and docs/SETUP.md in the project root for other platforms, privacy, limits and troubleshooting. Generation is local, but AI/OCR results still require checking. No fixed user identity, account or API key is required.
